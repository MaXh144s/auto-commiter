01 Registro GitHub

Gerar contribuição

A mensagem escolhida será registrada no log do repositório.

A pasta precisa ser um repositório Git válido.

Escolha uma pasta para validar o repositório.

Escolha um arquivo .txt ou .csv; uma mensagem será selecionada automaticamente.

Ao confirmar, a mensagem será adicionada ao log.md, seguida por git add ., commit e push.

⌂ O registro e o envio acontecem neste repositório.
